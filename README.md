# ClimaFlow

## Autor
Ágatha Castro — Matrícula: 22601851

## Descrição
O ClimaFlow é uma aplicação web para consultar o clima atual de uma cidade. O usuário informa o nome da cidade e recebe os dados de forma simples e organizada.

## API utilizada
- **Open-Meteo**
- Documentação: https://open-meteo.com/en/docs
- Geocoding: `https://geocoding-api.open-meteo.com/v1/search`
- Previsão atual: `https://api.open-meteo.com/v1/forecast`

## Funcionalidades
- Buscar uma cidade pelo nome.
- Consultar os dados atuais usando `fetch`.
- Exibir temperatura, sensação térmica, umidade e velocidade do vento.
- Exibir a condição do tempo e o fuso horário.
- Informar uma mensagem amigável quando a cidade não é encontrada ou ocorre erro na consulta.
- Permitir busca pelo botão ou pela tecla Enter.
